# Low-Level Design (LLD) Repository

Welcome to the **LLD Practice Repository**!  
This repository contains a collection of **Low-Level Design implementations in C++**, covering a wide range of real-world system design problems — from cache systems and parking lots to design patterns and OOP-based architecture challenges.

---

## What is/will be Inside

- **Design Pattern Implementations** (Singleton, Factory, Observer, Strategy, etc.)
- **System Design Simulations** (Parking Lot, Elevator, BookMyShow, Vending Machine, etc.)
- **Cache Implementations** (LRU Cache, LFU Cache, etc.)
- **OOP Practice Problems** (Snake & Ladder, Tic Tac Toe, Chess, etc.)
- **Utility Designs** (Logger System, File System, Rate Limiter, etc.)

Each folder contains:
- Clean, modular **C++ code**
- Proper **class structure and relationships**
- Inline **comments explaining design decisions**

---

## Tech Stack

- **Language:** C++  
- **Concepts Used:** OOPs, Design Principles (SOLID), Design Patterns  
- **Focus:** Clean code, extensibility, and maintainability

## Contributing

Contributions are **highly encouraged**!

1. **Fork** this repository 🍴  
2. **Create a new branch** (`git checkout -b feature-new-design`)  
3. **Add your code** under the relevant folder (or create a new one)  
4. **Commit and push** your changes  
5. **Create a Pull Request**
